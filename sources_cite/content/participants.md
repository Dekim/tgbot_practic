## Учебный проект в рамках проектной практики
Московский политехнический университет, кафедра информационных технологий
Группа 251-333 | Направление: 09.03.02 АСОИУ

**Weather Bot** — это Telegram-бот на Python, который позволяет получать актуальную информацию о погоде в любом городе мира. Пользователь вводит название города, и бот мгновенно возвращает подробный прогноз.

**Что умеет бот**:  
🌡️ Показывает текущую температуру и ощущаемую температуру  
💧 Отображает влажность воздуха  
💨 Сообщает скорость ветра  
🌥️ Описывает погодные условия с эмодзи  
🇷🇺 Поддерживает названия городов на русском и английском языках  
⚠️ Корректно обрабатывает ошибки при неверном названии города  

🛠️ **Стек технологий**
|Технология	|Назначение|
|---------------|----------|
|Python 3.x	|Язык программирования|
|pyTelegramBotAPI|Работа с Telegram Bot API|
|requests	|HTTP-запросы к OpenWeatherMap|
|OpenWeatherMap API	|Источник погодных данных|
|Git / GitHub	|Контроль версий|  

🚀 **Установка и запуск**
1. Клонируй репозиторий
git clone https://github.com/Dekim/tgbot_practic
cd weather-bot  

2. Установи зависимости
pip install pyTelegramBotAPI requests  

3. Настрой токены
Открой файл bot.py и вставь свои ключи  

4. Запусти бота: python bot.py  

💬 **Использование**
|Команда / Сообщение	|Результат|
|-----------------------|---------|
|/start	|Приветственное сообщение|
|/help	|Список команд|
|Москва	|Погода в Москве|
|London	|Погода в Лондоне|  

**Пример ответа бота**:  

🌤️ Погода в Москва


🌡️ Температура: +18°C  
🤔 Ощущается как: +16°C  
💧 Влажность: 62%  
💨 Ветер: 4 м/с  
📋 Условия: переменная облачность
